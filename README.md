# Agenda de Tarefas

Página de agenda mensal com tarefas, marcação de concluídas e planejamento do dia seguinte.

## Como ver no ar (GitHub Pages)

1. Crie um repositório novo em github.com (botão "New").
2. Envie o arquivo `index.html` (botão "Add file" → "Upload files").
3. Vá em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)` e clique em **Save**.
4. Depois de alguns minutos, o endereço aparece nessa mesma tela.

Os dados das tarefas ficam salvos só no navegador de quem usa a página.
